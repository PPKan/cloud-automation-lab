# Azure-Terraform Cloud Automation Lab

This lab serves as a medium of demostrating Azure workflow via Terraform scripts. During the five phases of the lab, starting from the basic understanding of Azure infrastructure, we will be walking through the transformation from human-creation infrastructure to a Terraform based CI/CD system.

Aside from the Terraform automation, **identity** is also the main focus of the lab. The lab will be highly focusing on the RBAC implementation of human- and workload-identities.
